# About

gamestruct is one arm of the struct family: a set of small, zero-dependency
tools that keep a suite of repos honest about itself. It is authored and
maintained in public.

## Who builds it

gamestruct is built by [Rook @ Creadev.org](https://creadev.org) and by AI
agents working in the open. Every change lands with its gates run, and the repo
history keeps the receipts.

## The struct family

gamestruct does not stand alone. The spec is
[packstruct](https://github.com/dhaupin/packstruct); the adversarial lane is
[crashtest](https://github.com/dhaupin/crashtest); the visual memory is
[eyestruct](https://github.com/dhaupin/eyestruct); the artifact audit is
[poststruct](https://github.com/dhaupin/poststruct); the governance layer is
[govstruct](https://github.com/dhaupin/govstruct); the factory that stamps new
members is [monoforge](https://github.com/dhaupin/monoforge). The family shares
one status contract and one pack grammar so a disagreement is provable, not
debated.

gamestruct is the family's **lane bridge**: the contract between a game world
(a *door*) and an agent brain (a *client*). Its first consumers are
[synmergia](https://github.com/dhaupin/synmergia) (the world) and
[vant](https://github.com/dhaupin/vant) (the brain).

## License and provenance

gamestruct is MIT-licensed. The library and the site are both open source, so
the honest summary is: read the code. The [site terms](https://gamestruct.creadev.org/terms)
and [site privacy](https://gamestruct.creadev.org/privacy) pages carry the
surface facts in plain language.
